# Calculator

A working calculator built with HTML, CSS and JavaScript. Handles the four basic operations with a keypad interface and a running display.

## Features

- Addition, subtraction, multiplication and division
- Clear and delete
- Decimal support
- Keyboard input alongside mouse clicks
- Responsive keypad layout

## Tech Stack

JavaScript, HTML, CSS

## Getting Started

```sh
git clone https://github.com/AMAY369/Calculator-Project.git
cd Calculator-Project
```

Open `index.html` in a browser.
